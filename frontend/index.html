GraphLab playground

Click empty paper to drop a node, or switch on Erase node and click one to remove it (its edges go with it). Drag from node to node to draw an edge. Click a node to set the start, shift-click to set the target. In weighted mode a box pops up on every new edge so you can type its own weight (negative is fine, Esc cancels the edge). Click a weight bubble to edit it, shift-click to delete the edge.
